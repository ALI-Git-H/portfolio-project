تعلم HTML من الصفر

HTML هي نقطة البداية لكل شخص يريد دخول عالم تصميم وتطوير مواقع الويب.

ما هي HTML؟

HTML اختصار لـ HyperText Markup Language، وهي لغة ترميز تُستخدم لبناء هيكل صفحة الويب. من خلالها نحدد العناوين والفقرات والصور والروابط والقوائم.

مثال عملي بسيط

الكود التالي ينشئ صفحة تحتوي على عنوان وفقرة:

example.html
<!DOCTYPE html>
<html lang="ar">
  <head>
    <title>صفحتي الأولى</title>
  </head>
  <body>
    <h1>مرحباً بك</h1>
    <p>هذه أول صفحة ويب لي.</p>
  </body>
</html>

أشهر عناصر HTML

<h1>عنوان رئيسي
<p>فقرة نصية
<a>رابط
<img>صورة
<ul>قائمة غير مرتبة
<button>زر
✦
